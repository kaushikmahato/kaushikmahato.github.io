My personal portfolio website and blog, migrated to an Astro-powered static architecture.

### Features
- **Astro**: High-performance static site generation.
- **Tailwind CSS**: Modern typography and responsive layout with Dark / Light mode.
- **Search**: Fast, static client-side search powered by Pagefind.
- **RSS & Sitemap**: Automatic RSS 2.0 feed and sitemap indexing.
- **CI/CD**: Automatic deployment to GitHub Pages via GitHub Actions.
